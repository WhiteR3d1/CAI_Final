# Boot & Bloom — ร้านซ่อมคอมจำลอง

เกมจำลองบนเว็บ ใช้เป็นสื่อการสอนเรื่อง**การติดตั้งระบบปฏิบัติการ Windows 10** ตามใบเนื้อหาของรายวิชา (15 หน้า)

ผู้เล่นเป็นช่างฝึกหัดในร้านซ่อมคอม ทำงานให้ลูกค้าทีละขั้นตามใบเนื้อหา:

| งาน | เนื้อหา | ใบเนื้อหา |
|---|---|---|
| 01 | สร้าง USB Boot ด้วย Rufus | หน้า 1–3 |
| 02 | ตั้งค่า BIOS ให้บูตจาก USB | หน้า 3–6 |
| 03 | ติดตั้ง Windows 10 ขั้นที่ 1–9 | หน้า 6–11 |
| 04 | ตั้งค่าเริ่มต้นขั้นที่ 10–16 และ Windows Update ขั้นที่ 17 | หน้า 11–15 |
| 05 | งานรวม: ลง Windows ใหม่ให้เครื่องที่มีข้อมูลลูกค้า | ทั้งหมด |

- ทุกงานมีการ์ดความรู้ ตัวอย่างจากช่างรุ่นพี่ หน้าจอจำลองให้ลงมือเอง ผลย้อนกลับเมื่อทำผิด และคำถามสรุป
- คะแนนมี 4 เกณฑ์: ความถูกต้อง, เหตุผลและหลักฐาน, การรักษาข้อมูล และการทดสอบหลังทำ
- คะแนนแยกจากเหรียญและของตกแต่งในเกม

> ชื่อเกมยังเป็นชื่อต้นแบบ

## เริ่มใช้งาน

```sh
npm install
npm run dev
```

เปิด URL ที่แสดงใน terminal ห้ามเปิดไฟล์ `index.html` ตรง ๆ คำสั่งอื่น ได้แก่ `npm test`, `npm run lint`, `npm run build`

## หมายเหตุ

- ยี่ห้อ รุ่นอุปกรณ์ และเว็บไซต์ในเกมเป็นของสมมติ ยกเว้นชื่อโปรแกรมที่อยู่ในใบเนื้อหา เช่น Windows 10 และ Rufus
- ไม่ใช้ภาพจากใบเนื้อหาหรือหนังสือ
- เนื้อหาที่ไม่อยู่ในใบเนื้อหาติดป้าย "เสริมนอกใบเนื้อหา"
- ผลการเล่นเก็บในเบราว์เซอร์เท่านั้น
