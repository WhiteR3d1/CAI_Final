# Boot & Bloom — ร้านซ่อมคอมจำลอง

เกมจำลองบนเว็บ ใช้เป็นสื่อการสอนเรื่อง**การติดตั้งระบบปฏิบัติการ Windows 10 และ Windows 11** ตามใบเนื้อหาของรายวิชา

ผู้เล่นเป็นช่างฝึกหัดในร้านซ่อมคอม ทำงานให้ลูกค้าทีละขั้นตามใบเนื้อหา มี 2 สาย เล่นสายไหนก่อนก็ได้:

| สาย | งานหลัก | ใบเนื้อหา |
|---|---|---|
| Windows 10 · Legacy BIOS (Rufus) | 01 USB Boot ด้วย Rufus, 02 ตั้ง BIOS บูต USB, 03 ติดตั้ง, 04 ตั้งค่าเริ่มต้น + Update, งานฝึก Microsoft (MCT), 05 งานรวมห้ามข้อมูลหาย | Win10 หน้า 1–15 |
| Windows 11 · UEFI (Media Creation Tool) | W11-01 ตรวจความพร้อม + สำรอง, W11-02 USB ด้วย MCT, W11-03 UEFI/Secure Boot/TPM, W11-04 Setup + OOBE, W11-05 ตรวจหลังติดตั้ง | Win11 หน้า 1–10 |

- **งานท้าทาย** สายละ 12 งาน ปลดหลังผ่านงานหลักที่สอนขั้นนั้น ไม่มีบทสาธิต ใช้หาเหรียญเพิ่ม
- ทุกงานมีการ์ดความรู้ ตัวอย่างจากช่างรุ่นพี่ หน้าจอจำลองให้ลงมือเอง ผลย้อนกลับเมื่อทำผิด และคำถามสรุป
- คะแนนมี 4 เกณฑ์: ความถูกต้อง, เหตุผลและหลักฐาน, การรักษาข้อมูล และการทดสอบหลังทำ
- คะแนนแยกจากเหรียญและของตกแต่งในเกม
- **ตกแต่งร้าน:**
  - ใช้เหรียญซื้อของตกแต่งได้ประมาณ 60 แบบ แล้วลากไปวางตรงไหนก็ได้
  - เปลี่ยนลายผนัง พื้น และป้ายร้าน ตั้งชื่อร้านเองได้
  - ของพิเศษปลดล็อกตามระดับร้าน
- **โชว์ร้าน:** เปิดร้านเต็มจอไว้แข่งกันในห้อง และบันทึกเป็นรูป PNG ส่งครูได้

> ชื่อเกมยังเป็นชื่อต้นแบบ

## เริ่มใช้งาน

```sh
npm install
npm run dev
```

เปิด URL ที่แสดงใน terminal ห้ามเปิดไฟล์ `index.html` ตรง ๆ คำสั่งอื่น ได้แก่ `npm test`, `npm run lint`, `npm run build`

## หมายเหตุ

- ยี่ห้อ รุ่นอุปกรณ์ และเว็บไซต์ในเกมเป็นของสมมติ ยกเว้นชื่อโปรแกรมที่อยู่ในใบเนื้อหา เช่น Windows 10 และ Rufus
- ไม่ใช้ภาพจากใบเนื้อหาหรือหนังสือ
- เนื้อหาที่ไม่อยู่ในใบเนื้อหาติดป้าย "เสริมนอกใบเนื้อหา"
- ผลการเล่นเก็บในเบราว์เซอร์เท่านั้น
